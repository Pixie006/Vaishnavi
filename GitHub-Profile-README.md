## 🚀 Featured Projects

### ReflectIQ — AI Journal & Cognitive Mirror

An AI-powered cognitive journal for private reflection and meaningful multi-turn conversations.

- Built with Gemini API, Firebase Authentication, Firestore and Cloud Run
- Designed per-user data isolation for privacy
- Used Google Cloud Secret Manager for secure credential management
- Added error handling and fallback support for reliability

### CymbalMart Party Planner

An AI-assisted event-planning and shopping application that creates personalised, budget-conscious plans.

- Generates curated shopping lists based on event type, theme, budget and guest count
- Provides an interactive AI assistant and browser-based voice control
- Recalculates budgets in real time when quantities or products change
- Includes preparation timelines, reminders and a checkout workflow

### AI-Based Bank Loan Processing System

A document-verification web application using Machine Readable Zone recognition to support loan-processing workflows.

- Extracts and validates identity-document information
- Applies AI and computer vision to reduce manual verification effort
- Developed as a final-year engineering project

### Vehicle Detection Over Zebra Crossing Lanes

A computer-vision system that detects vehicles violating zebra-crossing boundaries.

- Implemented object detection using YOLO
- Trained and evaluated models on a custom dataset
- Incorporated a time counter to support traffic-monitoring use cases
